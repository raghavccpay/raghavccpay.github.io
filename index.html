Questions

Are my files uploaded?

No. Compression, conversion, and PDF editing run in your browser. Closing the tab drops the file from memory.

Will a target size always be hit?

FileEase measures the real output and tries quality first, then smaller dimensions if you allow it. If the target would ruin the file, you get the closest honest result and a note.

Is a signature legally binding?

No. Drawn, typed, and uploaded signatures are images on the page. They are not certificate-based digital signatures.

What does redaction do?

The marked area is burned into a flattened page, so the text underneath is removed rather than hidden.

Why are some tools unavailable?

Legacy .doc and .ppt, and standard PDF passwords, need software this browser runtime does not include. Those tools stay disabled instead of faking a result.
